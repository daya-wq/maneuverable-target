# 可学习探索标准差修复（2026-10-22）

## 选择与实现

采用用户选择的第一种方法：保留全局可学习 log_std，使用优化后投影。
各输出通道各有一个参数；它们共享于环境、无人机与未来时间点，不是随状态变化的标准差网络。
当前位置/速度头有6个通道，即位置增量xyz、速度xyz；旧加速度头有3个通道。

- 新训练初始化：`log_std_init=-1.5`，`std=exp(-1.5)=0.223130`。
- 参数区间：`log_std_min=-3`、`log_std_max=0`，对应标准差约0.049787至1。
- 配置：`algo.actor.project_log_std=true`，默认MAPPO也启用此行为。
- 前向：`std=exp(log_std)`，不对log_std做硬clamp，梯度可经过该参数。
- 每次Actor优化后：在`no_grad`下将参数投影到`[-3,0]`。
- 旧检查点加载后：先投影再使用，修正旧参数略低于下限的问题。
- 统计和熵奖励采用同一有效参数；显式设值入口也保留边界限制。
- 标准差指tanh之前的高斯分布；经过tanh及物理动作解码后的扰动不恒等于这个数值。

投影能让下限处的参数继续收到梯度并向内部移动，不保证优化结果永远离开边界；
如果目标函数持续推动减小标准差，参数仍可能停在下限。
动作仍经原有tanh和位置/速度有界解码，探索范围变化不取消输出约束。

## 兼容与运行约定

`log_std`参数名、形状以及检查点格式不变。加载旧检查点时保留其有效标准差，
不会自动重置到-1.5；-1.5只用于新初始化。若要为旧模型重新扩大探索，需明确调用
`policy.set_actor_log_std(-1.5)`。现有训练入口的固定标准差调度保持关闭。
外部启动器显式传入`algo.actor.log_std_init`时会覆盖默认初值。

其他算法直接构造分布头时仍默认保留旧行为；MAPPO显式启用优化后投影。
本次不改变奖励、学习率、GAE、场景和输出头结构。
