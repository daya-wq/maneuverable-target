# 历史记录：四种目标战略与对抗场地说明

> 2026-10-28更新：本页正文保留旧实验场景供追溯，不是当前分支的网络配置。当前战略意图已合并为Goal_Rush/Evade两类，且预测仅一条轨迹；见`TWO_INTENT_SINGLE_TRAJECTORY.md`。原四意图版本见`archive/pv-sine-four-intent-20261028`。场地当前值以所选任务配置为准。

本文对应 `HideAndSeek + goal_defense` 主线。四种战略是目标当前意图的离散标签，用于战略意图 token 和监督预测；它们不是四套互相独立的追捕控制器。

## 1. 判定量

每个规划步计算两个距离：

- `d_goal`：目标位置到圆柱守区**表面**的最短三维距离。目标进入圆柱后该距离为0。
- `d_pursuer`：目标到三架追捕机中最近一架的欧氏距离。

当前阈值：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `target_goal_sprint_distance` | 1.0 m | 距守区表面不超过1 m时进入最后冲刺 |
| `target_tactical_far_distance` | 6.0 m | 最近追捕机不超过6 m时认为受到近距压力 |

## 2. 四种战略定义

判定有严格优先级：先看守区冲刺，再判断是否近距，最后在近距状态下比较两个距离。

| 编号 | 名称 | 精确条件 | 大白话解释 |
|---:|---|---|---|
| 0 | `FAR_RUSH` | `d_goal > 1.0` 且 `d_pursuer > 6.0` | 追捕机还远，目标以向守区推进为主 |
| 1 | `CLOSE_EVADE` | `d_goal > 1.0`、`d_pursuer <= 6.0` 且 `d_pursuer < d_goal` | 追捕机比守区更近，生存压力更大，优先规避 |
| 2 | `GOAL_PRIORITY` | `d_goal > 1.0`、`d_pursuer <= 6.0` 且 `d_goal <= d_pursuer` | 已受到近距压力，但守区更近，继续抢占守区更划算 |
| 3 | `GOAL_SPRINT` | `d_goal <= 1.0` | 已到守区最后1 m范围，最高优先级冲刺；不再由追捕距离改变标签 |

等价判定流程：

```text
d_goal <= 1.0 m ?
├─ 是：GOAL_SPRINT
└─ 否：d_pursuer <= 6.0 m ?
   ├─ 否：FAR_RUSH
   └─ 是：d_goal <= d_pursuer ?
      ├─ 是：GOAL_PRIORITY
      └─ 否：CLOSE_EVADE
```

边界值采用 `<=`：刚好1.0 m属于 `GOAL_SPRINT`，刚好6.0 m属于近距分支；当两个距离相等时属于 `GOAL_PRIORITY`。

## 3. 为什么把近距阈值从10.5 m改为6.0 m

旧阈值10.5 m几乎覆盖直径12 m的整个圆形场地。当前初始布局中，目标到守区表面通常约8.3–9.0 m，目标到最近追捕机通常约9.1–10.8 m，因此大多数样本从第一步就满足“近距且守区更近”，战略标签长期退化为 `GOAL_PRIORITY`。

改为6.0 m后，初始阶段先产生 `FAR_RUSH`；追捕机接近6 m后才进入 `CLOSE_EVADE/GOAL_PRIORITY` 分叉；目标接近守区表面1 m后再进入 `GOAL_SPRINT`。这使四个标签对应可解释的追逐阶段。阈值是否最终合理仍要看长训练的四类占比和切换率，不能只凭一次短测定论。

## 4. 对抗场地与关键区域

合法飞行区域是圆柱体，不是12 m × 12 m的方盒：

| 项目 | 当前配置 |
|---|---|
| 水平场地 | 以原点为圆心，半径6.0 m，直径12.0 m |
| 高度范围 | 地面到5.0 m |
| 撞地判定 | 任一追捕机 `z < 0.10 m` |
| 越界判定 | 任一追捕机水平半径 `sqrt(x²+y²) > 6.0 m`，或 `z > 5.0 m` |
| 守区 | 圆柱中心 `(4.0, 0.0, 2.5) m`，半径0.5 m，高1.0 m，即高度2.0–3.0 m |
| 抓捕条件 | 任一追捕机到目标距离不超过0.4 m |
| 擦肩超时条件 | 最终超时，且整局最近距离不超过1.0 m但未抓捕 |
| 单局最长时间 | 240个规划步 × 0.05 s = 12 s |

## 5. 每个episode的初始分布

| 对象/能力 | 采样范围 |
|---|---|
| 目标位置 | `x ∈ [-5.4,-4.8] m`，`y ∈ [-0.8,0.8] m`，`z ∈ [2.35,2.65] m` |
| 追捕机位置 | `x ∈ [4.3,5.3] m`，`y ∈ [-0.8,0.8] m`；相邻机至少1.0 m；高度相对目标不超过0.6 m并受场地高度限制 |
| 目标最大速度 | 每个episode独立均匀采样3.0–3.5 m/s |
| 目标最大加速度 | 每个episode独立均匀采样3.0–3.5 m/s² |
| 目标初始速度 | 0 m/s；与追捕机相同，从静止/悬停状态通过自身动力学加速 |

目标初始偏航角仍可随机，因为实机悬停时可以具有任意航向；不会在reset时注入线速度或角速度。目标能力上限只进入诊断信息，不直接作为Actor的特权输入。Actor需要从目标历史轨迹中推断它当前能跑多快、能多快改变速度，这更接近实机部署条件。

## 6. 越界处理

越界属于即时终止失败：只终止并自动重置发生越界的并行环境，不暂停整个训练任务。其终止奖励为-15，与撞地、机间碰撞和降落静止完全相同；统计字段为 `train/stats.termination_out_of_bounds`，原因编码为7。
