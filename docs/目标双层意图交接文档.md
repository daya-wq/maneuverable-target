# 目标双层意图交接文档

## 1. 概述

当前项目中的目标机采用“双层意图”规则，不依赖训练权重即可运行。后续学习模型也建议沿用这个双层定义，把“战略状态”和“短时机动模式”分开预测。

- 第 1 层是战略意图，用来判断目标当前是在远距离冲守区、近距规避，还是近守区冲刺
- 第 2 层是机动意图，用来判断目标短时局部动作风格

这套规则同时用于两处：

- 独立 6DoF 轨迹生成与分析
- `HideAndSeek` 主环境中的在线目标控制

这样可以保证离线生成的三维轨迹图、Isaac Sim 回放视频、以及环境内在线规则目标保持一致。

## 2. 战略意图

当前共有 3 类战略意图。这里不建议把“远距离直冲守区”和“近守区冲刺”合并成同一类，因为它们对追捕方的意义不同：前者还有较长拦截时间，后者已经进入高风险终端阶段。

### 2.1 Far_Rush

触发条件：

- 最近追捕方距离 `> far_distance`

行为：

- 目标主要朝守区飞行
- 不叠加随机机动

默认参数：

- `far_distance = 6.0 m`

### 2.2 Close_Evade

触发条件：

- 最近追捕方距离 `<= far_distance`
- 且目标离守区 `> sprint_distance`

行为：

- 规避最近追捕方
- 远离其他追捕方
- 同时保持向守区推进
- 默认每 `1.0 s` 更换一次机动偏置
- 战略意图每 `0.5 s` 检查一次，若战略意图变化则立即刷新机动方式

默认参数：

- `tactical_check_period = 0.5 s`
- `maneuver_update_period = 1.0 s`
- `sprint_distance = 2.0 m`

### 2.3 Goal_Sprint

触发条件：

- 目标离守区 `<= sprint_distance`

行为：

- 只朝守区冲刺
- 不叠加随机机动

## 3. 新增规则：守区优先规避

这是加在 `Close_Evade` 内部的一条补充规则。

触发条件：

- 当前仍属于 `Close_Evade`
- 且 `目标离守区距离 < 目标离最近追捕方距离`

行为：

- 仍然保留规避框架，但“冲守区”成为主要占比
- 守区吸引力大于普通近距规避状态
- 规避力降为次要占比
- 暂停 `1.0 s` 随机机动切换
- 机动模式锁为 `Straight`

设计目的：

- 避免目标已经更接近守区时，还被随机机动打断推进
- 保持“会规避，但总体更像抢守区”的行为风格

## 4. 机动偏置

机动意图固定为以下 9 类，现阶段不再继续扩展类别。

- `Straight`
- `Left-Turn`
- `Right-Turn`
- `Climb`
- `Dive`
- `Left-Climb`
- `Left-Dive`
- `Right-Climb`
- `Right-Dive`

其中：

- 普通 `Close_Evade` 下会按周期随机切换
- `Far_Rush`、`Goal_Sprint`、守区优先规避下都不使用随机切换
- 若后续训练中出现低速难判定片段，优先在数据侧过滤或并入 `Straight`，暂不新增新的机动类别

## 5. 学习模型输入与频率约定

### 5.1 战略意图输入

战略意图分类必须包含守区信息。原因是 `Far_Rush` 和 `Goal_Sprint` 都可能表现为“目标朝守区方向直飞”，仅看目标和追捕方的位置、速度不足以判断目标是刚开始远距离冲守区，还是已经接近守区进入终端冲刺。

建议输入：

- 目标位置、速度
- 追捕方位置、速度
- 守区中心位置
- 目标到守区的相对向量与距离
- 目标到最近追捕方的距离
- 目标速度在守区方向上的投影

### 5.2 机动意图输入

机动意图仍然使用同一段历史数据，但标签固定为第 4 节的 9 类局部机动。机动意图更关注短时轨迹形态，例如转弯、爬升、俯冲及其组合。

建议输入：

- 目标位置、速度历史
- 目标相对追捕方的位置、速度历史
- 可保留守区相对向量作为上下文，但机动标签本身以短时局部运动形态为主

### 5.3 采样频率与窗口

意图预测频率和轨迹预测频率可以不统一。

- 战略意图输入窗口：`0.5 s`
- 机动意图输入窗口：`0.5 s`
- 意图输入采样间隔：`0.05 s`
- 意图输入帧数：`10` 帧
- 轨迹预测窗口：`0.5 s`
- 轨迹预测采样间隔：`0.02 s`
- 轨迹预测帧数：`25` 帧

这样设计的含义是：意图分支用较低频率观察整体态势，轨迹分支用更高频率保留未来轨迹细节。两者可以共享编码器的一部分，也可以使用不同时间分辨率的分支后再融合。

### 5.4 推荐输出

- `strategic_intent_logits`: 3 类战略意图
- `maneuver_intent_logits`: 9 类机动意图
- `future_trajectory`: 未来 `0.5 s` 目标轨迹，`0.02 s` 一个点

## 6. 关键参数

当前常用参数如下。

### 6.1 场地与守区

- 场地半径：`6.0 m`
- 场地高度：`5.0 m`
- 守区中心：`[5.0, 0.0, 2.5]`
- 守区半径：`0.5 m`
- 守区高度：`1.0 m`

### 6.2 目标规则参数

- `target_tactical_far_distance = 6.0`
- `target_goal_sprint_distance = 2.0`
- `target_far_goal_gain = 1.0`
- `target_near_goal_gain = 1.0`
- `target_goal_sprint_gain = 1.6`
- `target_goal_priority_gain = 2.4`
- `target_goal_priority_repulsion_scale = 0.45`
- `target_nearest_repulsion_coef = 1.8`
- `target_other_repulsion_coef = 1.0`
- `target_maneuver_force_coef = 0.9`
- `target_maneuver_forward_scale = 0.4`
- `target_maneuver_vertical_scale = 0.9`
- `target_maneuver_speed_threshold = 0.3`

### 6.3 动力学与约束

- 双方最大速度：`3.0`
- 双方最大加速度：`3.0`
- 目标最小高度：`0.2 m`

说明：

- 独立 6DoF 轨迹生成脚本中也使用相同量级的约束
- Isaac 主环境中还会结合 UAV 控制器参数执行速度/姿态跟踪

## 9. 后续维护建议

- 若调整战略规则，优先同时修改 `dual_intent_target.py` 与 `hideandseek.py`
- 若只改了环境侧而没改独立控制器，会导致离线轨迹与在线仿真行为不一致
- 若调参数，优先记录这几项：`far_distance`、`sprint_distance`、`goal_priority_gain`、`goal_priority_repulsion_scale`
- 若重新出图或出视频，建议同步更新 `results/dual_intent_6dof_battles/` 下的汇总文件
